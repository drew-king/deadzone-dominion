# Approved player feedback

Each JSON file in this directory is a moderator-approved roadmap item keyed by its Discord forum thread ID. Items enter the published roadmap after the related GitHub PR is merged. Never put Discord user content or private reports into an entry verbatim. Use a short, de-identified summary and measurable acceptance criteria.

Run `node tools/feedback-bot/build-devhub.mjs` from the repository root before saving the next Dev Hub version. Git remains the source for approved feedback. Record the merged revision alongside the Hub version.

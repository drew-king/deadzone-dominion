# Deadzone Dominion

Open this folder in Visual Studio Code. If Rojo is stopped, run `.\tools\rojo\rojo.exe serve --port 35011` from the project root with the local Rojo 7.7.1 executable. Connect the Studio plugin to `localhost:35011`, then press Play to generate the Phase 1 map.

## Project layout

- `src/shared` maps to `ReplicatedStorage/Shared`
- `src/server` maps to `ServerScriptService/Server`
- `src/client` maps to `StarterPlayer/StarterPlayerScripts/Client`
